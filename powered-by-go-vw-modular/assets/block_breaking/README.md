# Block breaking cracks

`cracks-atlas.png` is a transparent 128x16 PNG containing eight 16x16 stages, ordered left to right. Stage 0 is completely transparent; stage 7 has the densest cracks. The separate `cracks-0.png` through `cracks-7.png` files contain the same frames. `cracks-grid.png` arranges them in four columns and two rows. `cracks-preview.png` is an enlarged preview with a gray background; use the transparent assets in the game.

For a Godot AtlasTexture, set the region to `(stage * 16, 0, 16, 16)` on `cracks-atlas.png`. Use nearest texture filtering for sharp pixels. These assets have not been connected to the game's breaking system yet.

Generated with the built-in image generation tool, then exported to the exact pixel dimensions. The final generation prompt was:

> Improve this crack sprite atlas for downsampling to exactly 64x32 pixels (4 columns x2 rows, each tile16x16). The current cracks are too thin: they become disconnected dots when reduced to 16x16. Make each crack a CONNECTED stepped pixel-art fissure. Crucial: every stroke must be at least ONE SIXTEENTH OF A TILE'S WIDTH (about 28 physical pixels when each tile is443 pixels wide). Use chunky square logical pixels, NOT hairline cracks, NOT subpixel gray accents. Think of drawing on a true 16x16 pixel grid then enlarging exactly. Keep all cracks near-black and fully opaque; everything else alpha0. Stage0 upperleft completely transparent. Stage1 tiny connected stepped 3-pixel crack at center. Stage2 same crack extending in a diagonal zigzag. Stage3 add a connected branch, stage4 extend toward edges, stage5 more connected branches, stage6 broad interconnected crack network, stage7 full spiderweb of connected jagged fractures reaching all sides with plenty of transparent regions between them. Each stage preserves and grows the previous crack shape. Keep equal-sized aligned cells, no padding. NO isolated dots, NO noise, NO semi-transparent pixels, NO gradient, NO surface/background, NO borders, NO text, NO painted checkerboard. Return actual transparent PNG of only the connected pixel cracks.
